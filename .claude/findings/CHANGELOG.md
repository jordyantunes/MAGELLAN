ROOT CAUSE CONFIRMED. Reverting only the sr_update return-value/gather change from 4f33ebe (keeping perf timers, mlflow.log_artifacts, and the alpha_loss reorder intact) fully restores healthy learning: grasp>=0.5 by ep 5004, >=1.0 by ep 10007, stable through 20000 episodes, zero collapses. This isolates the entire multi-week regression to a single change: capturing the return value of agent.update(func='sr_update') and adding a corresponding mlflow.log_metrics call in main.py (magellan/updater.py's sr_update branch changed from an implicit `return None` to `return {**perf.as_metrics(...), **gpu_mem_snapshot(...)}`, and main.py started capturing that into sr_update_results and logging it). The SR update path uses the same lamorel distributed IPC (Caller.update -> dist.gather_object across the RL and LLM worker processes) as sac_update; adding a gathered return payload here where none existed before evidently perturbs that shared distributed channel in a way that corrupts or desyncs the actor/critic learning path, despite the SR loss computation itself being unaffected (sr_impossibles was already known-healthy throughout the whole regression).

**vs. prior run:** Confirms and narrows the fc48b71d (4f33ebe, unmodified) finding: that run was stuck exactly like every post-07-20 run. This run, identical except for the one revert, is healthy -- pinpointing the sr_update return-value change as the sole cause, and fully exonerating 0caf5f2 (TF32/mask/empty_cache), the perf-timer wrapping in general, the alpha_loss reorder, and mlflow.log_artifacts.

- **BUG** `test/grasp`: Root cause of the 07-20 through 07-25 grasp regression identified: magellan/updater.py SACUpdater.update()'s sr_update branch returning a perf/gpu-mem metrics dict (added in commit 4f33ebe) instead of implicitly returning None, combined with magellan/main.py capturing that return value via `sr_update_results = agent.update(..., func='sr_update', ...)` and gathering/logging it. Reverting just this one change (while keeping every other 4f33ebe/0caf5f2 change: perf timers, TF32, pad-mask vectorization, empty_cache gating, mlflow.log_artifacts checkpoint upload) fully restores healthy learning.
